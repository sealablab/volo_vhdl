### Background:

Many higher level applications built on top of this project have a very common use-case / abstraction:

Given a pre-defined and specific voltage range, create a LUT/datatype that a `7-bit unsigned` index will correspond obviously with the human scale notion of base ten percentage.

#### S2) new package
 Help me generate a new package / datatype to replace it. Maybe you can even help with the name.

Help me design a solution with the following prioirities
### PRI-01:
**completely** arbitrary voltage ranges are not a huge motivator. If a generic solution lends itself naturally to arbitrary ranges can be found, that is fine. 

### PRI-02:
 A handful of common and  pre-defined ranges is entirely acceptable. These would include the obvious ones mentioned above and maybe a few more. 

### PRI-03:
- would like to make this 'percentage' (aka 'intensity') into a somewhat type-safe entity.  I,.e, advanced users can always assign one to or from a `std_logic_vector`, but the compile time checks should prevent it. 

- Obvious caveats of this would be: an application trying to use one 'intensity' or 'percentage' type in the wrong assignment. (i.e. a 3v3 intensity asssigned to a 5v0) should be treated as a compile time error. 

### PRI-04
There are no hard constraints on backwards compatailbity with any existsing code. If we can find an elegant way to implement this it will become a widely used developer pattern once introduced.
